# template.md の形式（lt-content の出力 ＝ lt-deck の入力）

lt-deck の原稿担当は、このファイルを読んで `script.md` を書く。原稿担当が読むのは次の3点：

1. 第1部（事実）：台本の記述が事実にあるかを突き合わせる基準
2. 第2部の時間配分の表：スライドの秒数配分の出発点
3. 第2部の台本：話す原稿の下書き（`>` の引用ブロック）

## 全体の構成

見出しのレベルと名前は変えない（原稿担当とレビュー担当が見出しで探す）。

```markdown
# LT：<タイトル（伝えたいことを短く）>

<YYYY-MM-DD> · <発表者名（未定なら ○○）>

---

## 第1部：話した内容のまとめ

### 前提

- <立場>。最近の仕事は、<…>
- LTのテーマは「<…>」
- 聴衆は<社内／社外／未定>
- 持ち時間は<N>分

### <話題1の見出し>

- <本人が言ったこと>
  - 例：<具体例>
- <補った箇所>【要確認】

### <話題2の見出し>

- …

### これからの改善

- <やろうとしていること>
- まだ実行には移せておらず、これから取り組む段階   ← 未実行なら必ず書く

### LTで一番伝えたいこと

「<本人の言葉で1文>」

---

## 第2部：台本（<N>分）

### 概要

伝えたいことは1つ。「<1文>」。持ち時間は<N>分、台本は<実測の字数>字、<持ち時間−30秒>で話し終えるのが目標です。

| パート | 時間 | 中身 |
| --- | --- | --- |
| つかみ | 25秒 | <…> |
| <パート2> | 40秒 | <…> |
| <パート3> | 95秒 | <…> |
| 気づき | 60秒 | <…> |
| これから | 50秒 | <…> |
| 合計 | 270秒 | |

### 1. つかみ（25秒）

スライド：<スライドに載せるもの>

> <話す台本>
>
> <話す台本>

<演出メモ（一拍置く、ゆっくり話す、など）>

### 2. <パート名>（40秒）

…

### <N>. これからと締め（50秒）

スライド：<…>、最後にタイトルを再掲

> …

### 練習と準備

台本は全体で<実測の字数>字です。一度タイマーで通して話し、超えたら下の順に削ってください。

1. <パート番号>の「<第1部にない補足>」
2. <パート番号>の「<主張を支える文>」

本番前に決めること：

- [ ] 名前を「○○」に入れる      ← 未定のときだけ
- [ ] 社内LTか社外LTかを確認する  ← 未定のときだけ
- [ ] タイマーで通し練習し、<持ち時間−30秒>以内に収める
```

## 第1部のルール

- 本人が言ったことだけ。推測・一般化・Claude の補足には `【要確認】` を付ける（lt-deck に渡す前に本人確認して消す）
- 範囲の限定（「1回目のレビューのときだけ」など）は本人の言葉どおりに書く
- 未実行のことは「まだ実行には移せておらず」と明記する
- 公開してよいか未確認の固有名詞は、第1部では本人の言葉のまま書き、第2部で一般的な言い方にする

## 第2部のルール

| 項目 | ルール |
| --- | --- |
| 時間配分の表 | 時間は**秒**で書く（「1分45秒」でなく「105秒」）。最後に合計行を入れ、合計は「持ち時間 − 30秒」以内 |
| パート見出し | `### N. パート名（M秒）`。M は表と同じ値 |
| 台本 | 話す言葉は `>` の引用ブロックだけに書く（字数を数える対象）。演出メモは引用の外 |
| 字数 | 1秒5字で見積もる（パートごとに 秒数×5 字前後、5.5字/秒を超えない）。台本の実測値を Python で数え、**概要と「練習と準備」に同じ1つの数値**を書く |
| 固有名詞 | 社外・未定：技術スタックやコードが分かる名前を出さない（例：govulncheck → 「脆弱性スキャンツール」）。社内：本人が出してよいと言ったものだけ |
| 中身 | 第1部にある事実から作る。第1部にない補足は「削る候補」の先頭に入れる |
| 構成 | 主張は1つ、具体例は2つまで。山場のあとに新しい論点を足さない。締めでタイトルを再掲 |
| 削る候補 | 「練習と準備」に番号付きで書く。順は「第1部にない補足」→「主張を支える文」。山場は入れない |

## 書式の注意（前回崩れたところ）

- タイトル行は `# LT：…`（`# #` にしない）
- Markdown をエスケープしない：`**太字**`、`> 引用`、`- [ ] チェック` をそのまま書く（`\*\*`、`&gt;`、`\[ \]` にしない）
- 行末に余分な空白を入れない

## lt-deck の原稿担当への対応表

| template.md | script.md（lt-deck） |
| --- | --- |
| 第2部の表のパート | スライドのまとまり（1パートを1〜2枚に分けてよい。5分なら8枚前後） |
| `### N. パート名（M秒）` の M | `## スライドN：パート名（M秒）` の秒数の出発点 |
| 「スライド：…」の行 | 「スライドに載せる文言」 |
| `>` の台本 | 「話す原稿」 |
| 引用の外の演出メモ | 「演出メモ」 |
| 「練習と準備」の削る順 | 「削る候補①②…」 |
| 第1部 | 台本にしかない記述を見つけるための事実の基準 |
